# Go Assembler calculations

Набор алгоритмов на ассемблере Go для архитектуры amd64 с тестами на Go.

## Инструментарий

- Go 1.25.0.
- Ассемблер Go (синтаксис Plan 9), инструкции x86-64.
- `testing` и `testify/require` для тестирования.

## Что реализовано

- `internal/sequence` — вычисление n-го числа Фибоначчи (`uint64`).
- `internal/slices` — сумма элементов среза `[]int32` с результатом `int64`.
- `internal/search` — двоичный поиск нижней границы (`LowerBound`) в отсортированном по возрастанию срезе `[]int64`: индекс первого элемента не меньше заданного значения или длина среза, если такого элемента нет.

## Запуск тестов

На машине с архитектурой amd64:

```sh
go test ./...
```
